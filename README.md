# Development repository of the Modeling Utility for Simscape™

This is a development repository for the Modeling Utility for Simscape.

Development is made under the `Devel` folder.
In MATLAB, cd to the `Devel` folder and run `setup_paths` to set up the MATLAB® path for development.

The `Release` folder is used to create a release.
